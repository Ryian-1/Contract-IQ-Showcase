# Contract IQ

**AI-Assisted Contract Review for macOS**

Contract IQ is a macOS application built with SwiftUI that supports structured contract review and negotiation workflows.

### Project highlights

- AI-assisted clause drafting and revision
- Negotiation playbooks and fallback positions
- Original-versus-proposed clause comparison
- Revision history and human review workflows
- Structured Markdown review-package export

### Technology stack

Swift · SwiftUI · AppKit · Firebase Authentication · Cloud Firestore

### About

This project explores how AI can support contract workflows while keeping human review central to decisions about proposed contractual language.

AI-generated contract language should be reviewed by a qualified legal professional before use in an actual agreement.
